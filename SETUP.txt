Dun — local setup
=================

Windows, Mac, or Linux.

1. Install Node.js 22+ from https://nodejs.org
2. Unzip this archive
3. In a terminal:

   cd dun
   npm install
   npm run dev

4. Open the URL it prints.

If `npm run dev` fails with spawn vite ENOENT, run:

   npx vite dev --host 0.0.0.0 --port 8080
