Dun — local setup
=================

1. Install Node.js 22 or newer from https://nodejs.org
2. Unzip this archive
3. In a terminal:

   cd dun
   npm install
   npm run dev

4. Open the URL it prints in your browser.

Guest mode works with no account. Create an email account to sync and share Circles.

Phone app (PWA)
---------------
Open that URL in Safari (iPhone) or Chrome (Android), then Add to Home Screen / Install app.
